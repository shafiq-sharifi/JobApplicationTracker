# JobApplicationTracker

## Projektbeskrivning

JobApplicationTracker är ett konsolprogram som jag har utvecklat i C#.

Programmet hjälper användaren att hålla reda på sina jobbansökningar.

Med programmet kan man:
- Lägga till nya jobbansökningar.
- Visa alla ansökningar.
- Filtrera ansökningar efter status.
- Sortera ansökningar efter datum.
- Visa statistik.
- Uppdatera status på en ansökan.
- Ta bort ansökningar.
- Spara och läsa in ansökningar med JSON.

## Hur man kör programmet

1. Öppna projektet i Visual Studio Code.
2. Öppna terminalen.
3. Skriv följande kommando:

```bash
dotnet run
```

4. Välj ett alternativ i menyn för att använda programmet.
